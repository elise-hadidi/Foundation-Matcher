# AI Foundation Shade Matcher

This is a simple AI-powered tool that analyzes selfies to recommend the closest foundation shade using computer vision and color clustering.

## Features
- Upload a selfie
- Detect dominant skin tone
- Match to foundation shades
- Display color swatch and recommendation

## Tech
- Python
- Streamlit
- OpenCV
- K-Means Clustering

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
